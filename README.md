# NeuroGraph
In basic words (Project Explanation) :

When someone has a tremor (like early Parkinson's), their hand shakes slightly while writing — you can't always see it, but a digital pen tablet can measure it: how much pressure changes, how fast the pen moves, how jittery the strokes are. You turn those measurements into numbers (features), then teach a machine learning model to recognize the difference between a steady hand and a shaky one. The novel part is which numbers you invent and how you combine them — not the machine learning algorithm itself.
